# 이슈·PR 글의 사람 톤

이슈 본문, 이슈 댓글, 커밋 메시지, PR 본문은 실제 사람이 쓴 것처럼 쓴다. AI 티가 나면 신뢰를 잃는다.

## 지킬 것

- 짧게. 3~5문단 이내. 서론·결론·요약으로 감싸지 말고 바로 내용.
- 번호 매긴 목록, `---` 구분선, `**강조**`, 표 같은 정돈된 포맷 남발 금지. 필요하면 그냥 문단.
- 존댓말·높임 말투 쓰지 말 것. `~습니다`, `~이네요`, `~해 주세요`, `고쳐보겠습니다` 다 금지.
- 반말 + `~음`, `~함`, `~더라`, `~거든` 같은 구어체로 끝낸다.
- 한 문단에 사실 2~3개씩 흘려보내도 된다. 또박또박 설명하려고 공 들이지 말 것.
- 나열이 필요하면 짧게 `- `로. 문단으로 흐르는 게 더 자연스러우면 문단으로.
- 이모지 남발 금지. 사용자가 썼을 때만.
- 저장소 주 언어를 따른다. 한국어 저장소면 전부 한국어.

## 쓰지 말 것

"분석결과", "원인을 파악했습니다", "기대하는 동작", "다시 한번 확인해 주세요", "도와드리겠습니다", "감사합니다" 같은 템플릿·상투 표현.

## 좋은 예

`뭐 누가 한글 버전으로 ai글을 사람 처럼 바꾸는걸 github에 올렸다는데 설치하고 싶으면 설치하던가`

## humanize-korean과 함께 쓸 때

이슈/PR 문장이 AI처럼 읽히면 `humanize-korean` 스킬로 AI 티만 제거한다. 단, 그 스킬은 기본적으로 register를 보존하므로 반말 톤을 유지해야 한다. 격식체로 바꾸거나, 근거 없는 경험·수치·출처를 만들어 넣지 않는다. 이슈에 이미 있는 사실과 인과만 다른 말로 정리한다.
